## Architecture implemented
1. **YtCore web replacement** — `modules/yt-core/index.web.ts` (Metro platform-specific resolution; `index.ts` native unchanged; shared types extracted to `modules/yt-core/types.ts`). Provider chain: Piped instances first (search+streams; pick m4a > webm audio, highest bitrate), then Invidious (search=video search; streams via `latest_version?itag=140|251&local=true`). Failed instances get a 5-min penalty (`failedUntil` map) to avoid serial timeouts. localStorage key `musico.backend` = user Piped instance override (tries first, no penalty skip) — Settings screen has a "Web backend" card to set it (web-only, Platform.OS check).
2. **SQLite web adapter** — `lib/sqlite.ts` (native, exports MusicoDb + openDb) vs `lib/sqlite.web.ts` (sql.js 1.13.0 asm.js build — deliberately NOT wasm so no COEP/SharedArrayBuffer headers needed; schema in shared `lib/db-schema.ts`). Web adapter implements execAsync/runAsync/getAllAsync/getFirstAsync via stmt.getAsObject; persists `db.export()` Uint8Array to IndexedDB `musico-db/sqlite/musico.db`, debounced 400ms, pagehide flush. `lib/db.ts` now imports openDb from ./sqlite and re-exports it (callers unchanged, all types MusicoDb).
3. **TrackPlayer web** — patched RNTP's `web/TrackPlayer/Player.ts` AND the compiled `lib/web/TrackPlayer/Player.js` (the build uses lib/) to drop shaka-player (uninstalled optional peer dep) → plain HTMLAudioElement appended to body, plus emits DeviceEventEmitter `Event.PlaybackError` so the app's error recovery (invalidateStream + retry once + skip) works. Patch captured via `npx patch-package react-native-track-player` → `patches/react-native-track-player+4.1.2.patch` (now includes the pre-existing Android MusicModule.kt fix + both web Player files). postinstall runs patch-package already.
4. **Downloads/local media** — `lib/local-media.ts` (native: expo-file-system getInfoAsync check) vs `lib/local-media.web.ts` (IndexedDB `musico-media/audio` Blobs via `lib/media-store.web.ts`; object URLs cached max 6, revoked on evict). `lib/downloads.ts` (native) vs `lib/downloads.web.ts` (same zustand store API: start/cancel/remove/resetStale; fetch + ReadableStream progress; abortable; localPath format "idb://musico-media/<id>.<ext>"). `lib/player.ts` now uses `getLocalPlayableUrl(song.id)` from ./local-media instead of expo-file-system directly. IMPORTANT: downloads.web.ts imports resolveStream from ./player — circular import exists (player.ts ← downloads.web.ts ← player.ts) same as native downloads.ts; works under Metro/Hermes but if you see TDZ errors, guard the call inside the function.
5. **MediaSession** — `lib/web-media-session.ts` (play/pause/next/prev/seekto handlers, metadata, playbackState). Called from PlaybackService() in lib/player.ts under `if (Platform.OS === "web")` via require() so native bundle never includes it.
6. **app.json** — web.output changed "static" → "single" (SPA so /player etc. don't 404 on static hosts without rewrites).
